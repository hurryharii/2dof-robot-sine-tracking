# 2-DOF Robotic Arm Simulation

## Overview

This project is a 3D simulation of a two-degree-of-freedom (2-DOF) robotic arm built using MATLAB, Simulink, and Simscape Multibody.

The model uses sine-wave input signals to produce robot motion and includes a subsystem named `FORWARD KINEMATICS`.

## Tools Used

- MATLAB
- Simulink
- Simscape Multibody

## Project File

- `robo2dof.slx` — the Simulink model file.

## What I Learned

- Creating a 3D robot model in Simscape Multibody.
- Exploring how components and joints connect in a robotic system.
- Using sine-wave signals as simulation inputs.
- Exploring forward kinematics in a robotics simulation.

## How to Run

1. Download or clone this repository.
2. Open MATLAB.
3. Navigate to the downloaded project folder.
4. Open `robo2dof.slx`.
5. Make sure the required toolboxes and supporting files are available.
6. Run the simulation.
